# PMS연구소 Figma 링크 모음

유관부서에 웹으로 나눠 주는 Figma 링크 목록 한 페이지입니다. `index.html` 하나가 전부이고, GitHub Pages(Actions)로 배포됩니다.

- 보기: https://osstemswai.github.io/pms-figma-links/
- 고치는 법: 워킹봇 `00_프로젝트/cloudX/output/4_보고/<날짜>_PMS연구소-Figma-링크-모음.html` 을 새로 만든 뒤 `index.html` 로 복사해 커밋 · push 합니다. 여기서 직접 고치지 않습니다.
- 페이지는 공개 URL입니다. 링크 이름과 주소만 있고, Figma 파일 자체는 Figma 권한이 있어야 열립니다.
